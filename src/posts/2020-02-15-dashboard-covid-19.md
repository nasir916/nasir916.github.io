Real-time dashboard to monitor the newly case(s) on 2019 Novel Coronavirus disease (COVID-19). This dashboard was developed using RStudio. The source of data is taken from “Tencent” (site address:https://news.qq.com/zt2020/page/feiyan.htm).

Initially, i have put maps in the dashboard, but i am unable to deploy it into Shiny server because of error of installing "sp" package in shiny server. But it work well in my local machine. 

Hope this will help us to understand the trend and monitor the series of incidence for this outbreak. 

The link for my dashboard is: [https://mohammad-nasir-abdullah.shinyapps.io/New12/](mohammad-nasir-abdullah.shinyapps.io/New12/)
