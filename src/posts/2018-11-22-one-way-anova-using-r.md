In this video, i am showing example of data analysis using one-way Analysis of Variance (ANOVA) method through R programming using R studio.

The purpose of one way ANOVA is to find the mean difference between groups (more than 2 categories). 

The requirement of the one way ANOVA are: 

1 numerical dependent variable

1 categorical independent variable with more than 2 levels.

Hope this video will help you to analyse data using one way ANOVA using R programming.
