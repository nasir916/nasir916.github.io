In this video, i am demonstrating on how to analyse data using Paired sample t-test using R-programming. 

The purpose of paired sample t-test is to find the difference between 2 repeated sample. 

Data requirement for paired sample t-test are :

1\) two numerical (repeated) dependent variable

2\) NO independent variable required.
