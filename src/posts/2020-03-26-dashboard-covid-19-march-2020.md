**Dashboard COVID-19 Kes Di Malaysia.** 

Saya ada buat satu dashboard untuk covid19 kes Malaysia.  
  
Sumber data adalah dari laman web MOH, outbreak.my dan ECDC.  
  
Tujuan dashboard ini dibina adalah untuk pembelajaran story telling data visualization, data scrapping dan dashboard.

  
  
Terima kasih kepada

 dan USM Health Campus kerana memberi ruang untuk dashboard ini di tempatkan dalam server RStudio Connect.

  
  
Dashboard ini sentiasa di update setiap hari pukul 6.30pm.
