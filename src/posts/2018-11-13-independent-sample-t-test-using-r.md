In this video, i am demonstrating on how to analyse data using Independent t-test via R-Programming. 

Independent t-test is used when we want to find the difference on mean dependent variable between categorical variable (with 2 levels).

The data requirement for Independent sample t-test are : 

1\) One numerical dependent variable.

2\) One categorical independent variable with 2 levels.  (eg: male & female).
